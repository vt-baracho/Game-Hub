## 📖 About the Project

**Game Hub** is a platform dedicated to bringing together fan-made
games inspired by existing games.

The project aims to provide a central place where players can
discover and access different fan-made experiences, while celebrating
creativity, experimentation, and game development.

Each game represents a different idea and interpretation,
bringing its own gameplay, mechanics, and challenges.

## ✨ Features

- A central page to access the game collection.
- Individual pages for each game.
- Search functionality to find games.
- Category filtering.
- A responsive interface for different screen sizes.
- A growing collection of fan-made projects.

## 🛠️ Technologies

The project uses web technologies:

- **HTML5** — Page structure and game interfaces.
- **CSS3** — Styling and responsive layouts.
- **JavaScript** — Interactions and game functionality.
